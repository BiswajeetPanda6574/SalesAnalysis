# Sales Data Analysis (EDA)
This project performs exploratory data analysis (EDA) on sales data across different states.


Tools: Python (Pandas, Matplotlib, Seaborn)

- Analyzed retail sales dataset
- Visualized category, region, monthly sales, segments, city
- Found top-performing regions and profit patterns

## Files
- `sales.eda.ipynb` : Jupyter Notebook with EDA
- `storesales.csv` : Dataset containing sales data
- `README.md` : This file
